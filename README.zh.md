## 概览

当前仓库还是一个较轻的项目骨架。从已提交的配置来看，它围绕 DeepSeek 模型参数和 TMDB API 接入来组织电影点评流程。

## 配置

在运行后续代码或自动化流程前，先将 `.env.sample` 复制为 `.env`，再补全相关 API 配置。
